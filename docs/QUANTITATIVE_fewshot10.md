# 정량 결과 — CA-LoRA with TimeStep Master (SDXL + Cityscapes)

> `python scripts/make_quantitative.py`로 원본 JSON에서 자동 생성. 손으로 고치지 말 것. 해석은 `docs/RESULTS.md`, 정성은 `docs/QUALITATIVE_2026-09-19.md`.

## 0. 프로토콜

- 생성: EulerDiscreteScheduler, 25 step, guidance 5.0, 1024 px, torch.float32, seed 0 (**1개, seed 간 분산 미측정**), 프롬프트 "photorealistic first-person urban street view" + 클래스명.
- 구성당 900장 = in_domain 500 + 날씨 4조건(foggy, night-time, rainy, snowy) × 100.
- CMMD: openai/clip-vit-large-patch14, 참조 Cityscapes val 500장, σ=10.0, ×1000. CLIP-Score 같은 모델. mIoU 미진행.
- 학습 데이터: train 2975장 중 무작위 10장 (seed 0, `runs/sdxl_cityscapes_fewshot10/training_subset.json`): aachen_000117_000019, cologne_000139_000019, dusseldorf_000172_000019, erfurt_000068_000019, erfurt_000070_000019, hanover_000000_001620, hanover_000000_055937, jena_000103_000019, zurich_000005_000019, zurich_000025_000019. fostering과 라우터 학습에만 쓰고, CA 측정·선택 집합은 전체 데이터 실험의 것을 그대로 쓴다.
